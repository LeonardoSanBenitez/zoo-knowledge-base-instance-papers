*Data codebook*
Project title: Data availability, reusability, and analytic reproducibility: Evaluating the impact of a mandatory open data policy at the journal Cognition
Data file titles: codingData.csv

This is data generated by coders using the Google Form (https://osf.io/qr6e4/) to assess data availability and in-principle reusability in Study One.

The data file has one row per article. Below we explain the columns in the data file and what they contain.

Timestamp: The data and time that article coding was completed
Coder intials: Initials of the individual who performed the coding
Article ID: A unique 5-character article ID code generated by TEH

The remaing columns are self-explanatory and correspond directly to the questions asked in the Google Form (https://osf.io/qr6e4/).
