*Data codebook*
Project title: Data availability, reusability, and analytic reproducibility: Evaluating the impact of a mandatory open data policy at the journal Cognition
Data file titles: statusData.csv

This is data indicating the status of articles during the project.

The data file has one row per article. Below we explain the columns in the data file and what they contain.

id: A unique 5-character article ID code generated by TEH


codingStatus: whether the article has been coded yet
passToTriage: does the article have available and in-principle reusable data, in which case pass to the "triage pool"
triageStatus: whether article has been rejected or accepted for a reproducibility check after being assessed for a "substantive finding based on a relatively straightforward analysis"
reproducibilityStatus: whether the article reproducibility check has been completed
