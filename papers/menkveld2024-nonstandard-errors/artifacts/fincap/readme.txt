#FINCAP DATA

The #fincap experiment described at https://fincap.academy resulted in a publication in the Journal of Finance ("Non-Standard Errors").  #fincap has from the very beginning been run in the spirit of Open Science.  The Journal of Finance further encourages the sharing of data for all articles it publishes.  The raw data, however, cannot be shared, because of privacy protection that had been guaranteed to all participants ex-ante.  It is for this reason that we make two files of anonymized data available.  These files are:

1. RT_research_results.xlsx
2. RT_beliefs.xlsx

The first file, RT_research_results.xlsx, contains research results for all research teams (RTs) for all four stages of the project.  The variable names should be self-explanatory.  These results, for example, were input for Table III of the published manuscript.

The second file, RT_beliefs.xlsx, contains the beliefs of RTs when they were asked before the start the experimment what they predicted the standard deviation of results across all RTs would be.  They were asked to predict the SD for both estimates and t-values.  The SD for estimates has been input for Figure 4 in the published manuscript.

Finally, this is all data that can be made available as per the contract between #fincap coordinators and #fincap participants.  Requests for more data will, therefore, necessarily be rejected.
