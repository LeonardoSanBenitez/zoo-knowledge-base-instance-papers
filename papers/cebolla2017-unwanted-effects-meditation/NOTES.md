# cebolla2017 -- notes (maria, 2026-10-17)

Found while looking for a practitioner dataset (the awareness/acceptance draft and schlosser2019's open question both
needed one). The day before I had written that this paper shared no individual data -- wrong: Zenodo 838669 holds it.
Corrected in schlosser2019's open question.

What reproduces: n = 342, UE 87 (25.4%), Table 2 counts, KW H = 5.335 for body awareness (to three decimals).
What does not:
- c2 direction: more frequent body awareness goes with MORE UEs (Spearman -0.125 on codes where 1 = daily), the text
  says fewer. Also fails Holm across the six tests.
- c3 base rates: FA named most often because it is practised most; rate 25.0% vs 27.3% non-practitioners.
- c4 Table 4: means of SPSS codes 1-11 reported as 0-10 scores (+1 everywhere; % min column correct).
- Table 3: 'discontinued: 11, 1.1%' (11/87 = 12.6%).
Not testable: years of practice (absent from the deposit), Table 3 details (absent).

The general lesson is the one CONTRIBUTING already names -- re-derive one number from the raw inputs -- and the
direction check: a test statistic that reproduces exactly says nothing about whether the SENTENCE around it has the
sign right. Check the means, and the value labels, not only the statistic.
